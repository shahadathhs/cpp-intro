# C++ Introduction & DSA Patterns

This repository contains a structured introduction to C++ and basic Data Structures and Algorithms (DSA) patterns. It is organized into topic-based folders, each containing explanations, code examples, and practice problems.

## Structure

Each folder contains a `README.md` with detailed theory, time complexity tables, and explanations.

- **[01_basics](01_basics/README.md)**: Introduction to C++, data types, operators, conditionals, and loops.
- **[02_pointers](02_pointers/README.md)**: Pointers, references, and memory management.
- **[03_functions](03_functions/README.md)**: Function declaration, parameters, return values, and scope.
- **[04_arrays](04_arrays/README.md)**: Arrays, array operations, and standard algorithms.
- **[05_strings](05_strings/README.md)**: String manipulation, standard library string functions, and detailed usage.
- **[06_recursion](06_recursion/README.md)**: Understanding recursion, base cases, and recursive stack.
- **[07_structs](07_structs/README.md)**: Structures, classes, and object-oriented basics.
- **[08_sorting](08_sorting/README.md)**: Sorting algorithms, comparators, and standard library sort.
- **[09_vector](09_vector/README.md)**: `std::vector` usage, initialization, capacity, modifiers, and iterators.

## Getting Started

1.  Navigate to a topic folder (e.g., `cd 01_basics`).
2.  Read the `README.md` to understand the concepts.
3.  Review the source code files for examples (e.g., `*.cpp` files).
4.  Compile and run the examples:
    ```bash
    g++ example.cpp -o example
    ./example
    ```

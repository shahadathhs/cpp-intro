# cpp-intro

This repository is reorganized into topic-based folders to help learn C++ and basic DSA patterns.

Structure:

- `01_basics/` — small beginner examples (I/O, loops).
- `02_strings/` — string manipulation and parsing problems.
- `03_arrays/` — array problems and related algorithms.
- `04_structs/` — examples using structs/classes.
- `05_sorting/` — sorting examples and comparator usage.
- `resources/` — sample `input.txt`, `output.txt`, and `sys.txt` used with examples.

Each folder contains the original source files moved from the repository root. Build and run individual `.cpp` files with your compiler of choice (for example `g++ -std=c++17 file.cpp -o file.out && ./file.out < resources/input.txt`).
